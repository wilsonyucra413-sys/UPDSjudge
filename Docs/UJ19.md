# UJ-19 - Congelamiento Automático del Ranking

## Descripción

Permite configurar un tiempo de congelamiento del ranking para que, durante los últimos minutos del concurso, los nuevos envíos aceptados no modifiquen públicamente la clasificación. Al finalizar el concurso, el ranking se actualiza automáticamente mostrando todos los resultados.

---

# Endpoints

## Configuración del congelamiento

**POST** `/api/Concursos/crear`

Permite definir el tiempo de congelamiento del concurso mediante el campo:

```
minutosCongelamiento
```

---

## Consulta para edición

**GET** `/api/Concursos/editar/{codigo}`

Permite recuperar la configuración del concurso, incluyendo el valor de:

```
minutosCongelamiento
```

Este valor puede modificarse únicamente mientras el concurso no haya iniciado.

---

## Aplicación del congelamiento

**GET** `/api/Concursos/{codigo}/ranking`

Es el endpoint encargado de aplicar automáticamente el congelamiento del ranking durante la competencia.

---

# Funcionamiento

El sistema calcula automáticamente el instante en que comienza el congelamiento utilizando la siguiente fórmula:

```
Inicio del congelamiento =
Fecha fin del concurso - Minutos de congelamiento
```

---

Mientras el concurso esté en curso:

- Si aún no inicia el congelamiento, el ranking se actualiza normalmente.
- Cuando comienza el congelamiento, los envíos realizados después de ese momento dejan de reflejarse públicamente en el ranking.

---

Al finalizar el concurso:

- El congelamiento se elimina automáticamente.
- El ranking vuelve a calcularse utilizando todos los envíos oficiales del concurso.

---

# Validaciones

## Configuración del tiempo de congelamiento

El tiempo de congelamiento se almacena al crear el concurso.

---

El tiempo de congelamiento puede modificarse únicamente antes del inicio del concurso.

---

## Aplicación durante el ranking

El congelamiento solamente se aplica cuando:

- El concurso está en curso.
- El tiempo de congelamiento es mayor que cero.
- Se alcanzó el momento de inicio del congelamiento.

---

Durante el congelamiento únicamente se consideran para el ranking los envíos oficiales realizados antes del inicio del congelamiento.

Los envíos enviados posteriormente permanecen registrados, pero no modifican la clasificación pública hasta finalizar el concurso.

---

# Respuesta

El endpoint del ranking devuelve un indicador que informa si el ranking se encuentra congelado.

Ejemplo:

```json
{
    "codigo": "upds-div4-001",
    "nombre": "Concurso Div4",
    "congelado": true,
    "participantes": [
        ...
    ]
}
```

---

# Reglas de Negocio

- El tiempo de congelamiento se configura al crear el concurso.
- La configuración puede modificarse únicamente antes del inicio del concurso.
- El congelamiento se aplica automáticamente durante los últimos minutos del concurso.
- Los envíos realizados después del inicio del congelamiento no actualizan públicamente el ranking.
- Al finalizar el concurso, el ranking se recalcula automáticamente utilizando todos los envíos oficiales.
- El congelamiento no elimina ni modifica los envíos almacenados; únicamente afecta la información mostrada en el ranking durante el concurso.
