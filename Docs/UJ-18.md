# UJ-18 - Visualización del ranking del concurso

## Descripción

Como **usuario**, quiero visualizar el ranking del concurso calculado según las reglas ICPC, considerando:

1. Cantidad de problemas resueltos.
2. Penalización (tiempo de resolución + 20 minutos por cada intento fallido antes del Accepted).

Esta funcionalidad permite consultar la clasificación oficial de los participantes de un concurso.

---

# Endpoint

**GET** `/api/Ranking/{codigoConcurso}/ranking`

Ejemplo:

```text
GET /api/Ranking/upds-div4-001/ranking
```

---

# Objetivo funcional

El endpoint genera el ranking oficial del concurso utilizando únicamente los envíos válidos para la competencia, calculando automáticamente la posición de cada participante.

---

# Validaciones realizadas

## 1. Código del concurso

El código del concurso es obligatorio.

**Si está vacío:**

```json
{
  "mensaje": "El código del concurso es obligatorio."
}
```

---

## 2. Existencia del concurso

Debe existir un concurso activo con el código indicado.

**Si no existe:**

```json
{
  "mensaje": "El concurso no existe o fue eliminado."
}
```

---

## 3. Estado del concurso

El ranking solamente puede consultarse cuando el concurso ya inició.

**Si el concurso aún no comienza:**

```json
{
  "mensaje": "El concurso todavía no ha iniciado."
}
```

---

## 4. Acceso a concursos privados

En concursos privados únicamente pueden consultar el ranking:

* participantes inscritos
* creador del concurso

**Si el usuario no tiene acceso:**

```json
{
  "mensaje": "No tienes acceso al ranking de este concurso."
}
```

---

# Cálculo del ranking

El ranking se calcula siguiendo las reglas de la competencia ICPC.

Para cada participante el sistema:

1. obtiene todos sus envíos oficiales del concurso;
2. agrupa los envíos por problema;
3. determina si el problema fue resuelto;
4. calcula el tiempo de resolución;
5. aplica la penalización correspondiente;
6. genera la clasificación final.

---

# Cálculo por problema

## Problema no intentado

Si el participante nunca realizó un envío al problema:

* Estado: **No intentado**
* Intentos: **0**

---

## Problema no resuelto

Si existen envíos pero ninguno fue **Accepted**:

* Estado: **No resuelto**
* Intentos: cantidad total de envíos realizados

---

## Problema resuelto

Cuando aparece el primer **Accepted**, el sistema calcula:

* tiempo transcurrido desde el inicio del concurso
* penalización por intentos fallidos previos

La penalización aplicada es:

```text
Tiempo final = minutos hasta Accepted + (20 × intentos fallidos)
```

Solo los intentos fallidos realizados **antes del primer Accepted** generan penalización.

Los envíos posteriores al primer Accepted no modifican el resultado del problema.

---

# Orden del ranking

Los participantes se ordenan utilizando los siguientes criterios:

1. Mayor cantidad de problemas resueltos.
2. Menor tiempo total acumulado.
3. Menor identificador de usuario (criterio de desempate).

---

# Empates

Si dos o más participantes poseen:

* la misma cantidad de problemas resueltos;
* el mismo tiempo total;

todos reciben el mismo puesto dentro del ranking.

---

# Congelamiento del ranking

Si el concurso posee minutos de congelamiento y actualmente se encuentra dentro de ese periodo:

* el ranking se marca como congelado;
* el endpoint informa dicho estado mediante el campo correspondiente.

# Reglas de negocio

* El concurso debe existir y encontrarse activo.
* El ranking solo puede consultarse cuando el concurso ha iniciado.
* En concursos privados solo pueden acceder los participantes inscritos y el creador.
* El ranking utiliza únicamente los envíos oficiales (`upsolving = "No"`).
* Un problema se considera resuelto únicamente con el primer **Accepted**.
* Cada intento incorrecto previo al Accepted agrega **20 minutos** de penalización.
* El tiempo total corresponde a la suma de los tiempos de todos los problemas resueltos, incluyendo la penalización.
* El ranking se ordena por problemas resueltos y luego por menor tiempo total.
* Los participantes empatados comparten el mismo puesto.

---

# Resumen funcional

La UJ-18 permite visualizar el ranking oficial de un concurso siguiendo las reglas ICPC, clasificando a los participantes según la cantidad de problemas resueltos y el tiempo total penalizado, mostrando además el detalle del desempeño obtenido en cada problema.
