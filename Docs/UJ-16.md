# UJ-16 - Envío de soluciones en modo Upsolving

## Descripción

Como **usuario**, quiero enviar soluciones a concursos finalizados para practicar sin afectar el ranking oficial del concurso.

Esta funcionalidad permite continuar resolviendo problemas una vez finalizado el concurso. Los envíos realizados en este modo se registran como **Upsolving** y **no son considerados para el cálculo del ranking oficial**.

---

# Relación con el envío de soluciones

El modo **Upsolving** forma parte del mismo endpoint utilizado para realizar envíos.

### Endpoint

**POST** `/api/envios/`

---

# Funcionamiento

Cuando un usuario envía una solución, el sistema determina automáticamente si el envío corresponde a:

* Concurso en curso.
* Concurso finalizado.

Si el concurso ya terminó, el envío se registra como:

```text
upsolving = "Si"
```

Si el concurso todavía forma parte de la competencia oficial, el envío se registra como:

```text
upsolving = "No"
```

Esta clasificación se realiza automáticamente y no depende de un parámetro enviado por el usuario.

---

# Ranking oficial

El ranking oficial únicamente considera los envíos realizados durante la competencia.

Para ello, durante el cálculo del ranking se recuperan únicamente los envíos cuyo campo:

```text
upsolving = "No"
```

Los envíos registrados como:

```text
upsolving = "Si"
```

son excluidos completamente del cálculo del ranking.

---

# Endpoint del ranking

**GET** `/api/Ranking/{codigoConcurso}/ranking`

---

## Validaciones realizadas

### 1. Código del concurso

El código del concurso es obligatorio.

**Si está vacío:**

```json
{
  "mensaje": "El código del concurso es obligatorio."
}
```

---

### 2. Existencia del concurso

Debe existir un concurso activo con el código indicado.

**Si no existe:**

```json
{
  "mensaje": "El concurso no existe o fue eliminado."
}
```

---

### 3. Estado del concurso

El ranking únicamente puede visualizarse cuando el concurso ya inició.

**Si el concurso aún no comienza:**

```json
{
  "mensaje": "El concurso todavía no ha iniciado."
}
```

---

### 4. Acceso a concursos privados

Si el concurso es privado, únicamente pueden consultar el ranking:

* participantes inscritos
* creador del concurso

**Si no tiene acceso:**

```json
{
  "mensaje": "No tienes acceso al ranking de este concurso."
}
```

---

# Cálculo del ranking

Para generar el ranking oficial el sistema:

1. obtiene los problemas del concurso
2. recupera únicamente los envíos con:

```text
upsolving = "No"
```

3. calcula el resultado obtenido por cada participante
4. ordena a los participantes según las reglas ICPC

Los envíos realizados en modo Upsolving nunca participan en este proceso.

---

# Reglas de puntuación

Para cada problema:

* si nunca fue aceptado, el problema se considera **No resuelto**
* si fue aceptado, se calcula el tiempo desde el inicio del concurso
* por cada intento incorrecto previo al Accepted se agregan **20 minutos** de penalización

El ranking se ordena por:

1. mayor cantidad de problemas resueltos
2. menor tiempo total
3. identificador del usuario (en caso de empate)

Si dos participantes tienen exactamente el mismo resultado, ambos comparten el mismo puesto.

---

# Reglas de negocio

* Los usuarios pueden seguir enviando soluciones después de finalizar el concurso.
* Los envíos realizados después de finalizar el concurso se registran automáticamente como **Upsolving**.
* El usuario no puede decidir manualmente si un envío es Upsolving.
* El ranking oficial únicamente utiliza los envíos cuyo campo `upsolving = "No"`.
* Los envíos de Upsolving nunca modifican la clasificación oficial del concurso.
* La separación entre competencia oficial y práctica se realiza mediante el campo `upsolving`, no mediante la fecha del envío.

---

# Resumen funcional

La UJ-16 permite que los usuarios continúen practicando una vez finalizado un concurso mediante envíos en modo **Upsolving**. Estos envíos son almacenados normalmente, pero quedan excluidos del ranking oficial gracias al uso del campo `upsolving`, garantizando que la clasificación obtenida durante la competencia permanezca inalterada.
