# UJ-20 - Consulta de Mis Envíos

## Descripción

Permite al usuario consultar el historial de todos sus envíos realizados, con la posibilidad de filtrar por concurso, veredicto obtenido e inciso del problema.

---

# Endpoint

**GET** `/api/Envios/mis-envios`

---

# Parámetros de Consulta

| Parámetro | Tipo | Obligatorio | Descripción |
|-----------|------|-------------|-------------|
| resultado | String | No | Filtra los envíos según el veredicto obtenido. |
| concursoCodigo | String | No | Filtra los envíos por código del concurso. |
| inciso | String | No | Filtra los envíos por inciso del problema. |
| pagina | Integer | No | Número de página. Valor por defecto: **1**. |
| tamanoPagina | Integer | No | Cantidad de registros por página. Valor por defecto: **20**. Máximo **50**. |

---

# Veredictos Disponibles

El parámetro `resultado` acepta las siguientes abreviaturas:

| Código | Veredicto |
|---------|-----------|
| AC | Accepted |
| WA | Wrong Answer |
| TLE | Time Limit Exceeded |
| MLE | Memory Limit Exceeded |
| CE | Compilation Error |
| RE | Runtime Error |

También es posible enviar directamente el nombre completo del veredicto.

---

# Validaciones

## Paginación

- La página mínima permitida es **1**.
- Si el tamaño de página es menor a **1** o mayor a **50**, se utiliza el valor por defecto de **20**.

---

## Filtro por resultado

Cuando se especifica un veredicto, únicamente se muestran los envíos que coincidan con dicho resultado.

---

## Filtro por concurso

Cuando se especifica un código de concurso, únicamente se muestran los envíos pertenecientes a concursos cuyo código coincida con la búsqueda.

La búsqueda es parcial y no distingue entre mayúsculas y minúsculas.

---

## Filtro por inciso

Cuando se especifica un inciso, únicamente se muestran los envíos correspondientes a dicho problema.

---

# Orden de los Resultados

Los envíos se muestran ordenados desde el más reciente hasta el más antiguo.

---

# Respuesta Exitosa

```json
{
    "total": 15,
    "pagina": 1,
    "tamanoPagina": 20,
    "datos": [
        {

            "inciso": "A",

        }
    ]

```

---

# Respuestas Posibles

| HTTP | Motivo |
|------|--------|
| 200 | Consulta realizada correctamente. |

---

# Reglas de Negocio

- Solo se muestran los envíos pertenecientes al usuario autenticado.
- Es posible combinar los filtros de concurso, veredicto e inciso.
- Los resultados se presentan de forma paginada.
- Los envíos se ordenan desde el más reciente al más antiguo.
- Los veredictos se almacenan y muestran en inglés siguiendo la nomenclatura utilizada por el sistema de evaluación.
